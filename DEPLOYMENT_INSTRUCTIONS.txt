OPTION 1 — RAILWAY.APP (Recommandé — Gratuit 500h/mois)
═══════════════════════════════════════════════════════════════

1. Créer un compte GitHub : github.com
2. Créer un dépôt "cryptoscanner" sur GitHub
3. Uploader tous les fichiers de ce dossier sur GitHub
4. Créer un compte Railway : railway.app
5. "New Project" → "Deploy from GitHub" → choisir ton dépôt
6. Dans "Variables" sur Railway, ajouter :
   TG_TOKEN = ton_token_telegram
   TG_CHAT  = ton_chat_id
   REPORT_HOUR = 8
   RUN_BACKGROUND_JOBS = true
   SECRET_KEY = une_cle_flask_stable
7. Railway détecte automatiquement le Procfile et lance l'app
8. URL fournie automatiquement : ton-app.railway.app

═══════════════════════════════════════════════════════════════
OPTION 2 — RENDER.COM (Gratuit — s'endort après 15 min)
═══════════════════════════════════════════════════════════════

1. Compte GitHub + uploader les fichiers
2. render.com → "New Web Service" → connecter GitHub
3. Start Command : gunicorn --worker-class eventlet -w 1 wsgi:application
4. Ajouter variables d'environnement (TG_TOKEN, TG_CHAT...)
   Ajouter aussi RUN_BACKGROUND_JOBS=true si ce service doit exécuter les scans
5. Deploy → URL fournie automatiquement

═══════════════════════════════════════════════════════════════
OPTION 3 — VPS HOSTINGER (5€/mois — 24h/24 sans limite)
═══════════════════════════════════════════════════════════════

1. Acheter VPS sur hostinger.fr (KVM1 - 5.99€/mois)
2. Se connecter en SSH : ssh root@IP_SERVEUR
3. Installer Python et dépendances :
   apt update && apt install python3 python3-pip -y
4. Uploader les fichiers (via SFTP ou GitHub)
5. pip install -r requirements.txt
6. Créer fichier .env avec TG_TOKEN et TG_CHAT
   Ajouter RUN_BACKGROUND_JOBS=true si tu veux les boucles de fond
7. Lancer en production :
   gunicorn --worker-class eventlet -w 1 --bind 0.0.0.0:5000 wsgi:application &
8. Pour 24h/24, créer un service systemd

═══════════════════════════════════════════════════════════════
VARIABLES D'ENVIRONNEMENT REQUISES
═══════════════════════════════════════════════════════════════

TG_TOKEN      = Token de ton bot Telegram (@BotFather)
TG_CHAT       = Ton Chat ID Telegram
REPORT_HOUR   = Heure du rapport automatique (défaut: 8)
RUN_BACKGROUND_JOBS = true pour activer scans/alertes dans le process web
SECRET_KEY    = Clé Flask stable pour cookies/sessions
DATABASE_PATH = Chemin SQLite personnalisé (optionnel)
ALPHA_VANTAGE_KEY = Clé API Alpha Vantage (optionnel - Forex)
WHALE_API_KEY = Clé API Whale Alert (optionnel)
VAULT_SECRET  = Clé de chiffrement (auto-générée si vide)
