# Architecture Microservices pour Crypto

## Résumé
Les architectures microservices permettent de déployer indépendamment chaque module (scanner, signaux, reporting).

## Points clés
- Chaque microservice gère une responsabilité unique
- Découplage via APIs REST ou event streams
- Scaling indépendant par composant
- Monitoring et observabilité critiques
