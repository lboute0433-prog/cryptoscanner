📊 COMPRENDRE LE POSITIONNEMENT INSTITUTIONNEL
🔴 LF Net — Leveraged Funds
Ce sont les hedge funds et traders spéculatifs. Ils ont souvent tort aux extrêmes — c'est un signal contrarien.

👉 LF très négatif (beaucoup de shorts) = les spéculateurs parient sur la baisse → signal haussier potentiel car ils devront racheter.
👉 LF très positif (beaucoup de longs) = marché peut-être surchargé → prudence.
🔵 AM Net — Asset Managers
Ce sont les grands fonds institutionnels (fonds de pension, assurances). Ils suivent la tendance — signal directionnel.

👉 AM en hausse / positif = les institutionnels accumulent → tendance haussière confirmée.
👉 AM en baisse / négatif = ils réduisent l'exposition → prudence.
🟣 OI — Open Interest
Nombre total de contrats ouverts sur le marché à terme CME. Mesure l'afflux de nouveaux capitaux.

👉 OI en hausse + prix en hausse = de l'argent frais entre → tendance saine.
👉 OI en baisse + prix en hausse = short squeeze possible, mouvement moins solide.
💡 Lecture combinée : Le signal le plus fort est quand les LF sont très shorts (signal contrarien haussier) ET les AM commencent à acheter (confirmation directionnelle) → les deux pointent dans la même direction haussière.

📌 Ces données proviennent du rapport CFTC (Commitment of Traders), publié chaque vendredi pour la semaine précédente. Disponible uniquement pour BTC et ETH (contrats CME).

📉 COMPRENDRE LE CVD — CUMULATIVE VOLUME DELTA
C'est quoi le CVD ?
Le CVD mesure la pression nette des acheteurs vs vendeurs sur les contrats perpétuels. Chaque bougie, on calcule : delta = volume × (ratio achat − ratio vente)

Le CVD = somme cumulative de ces deltas. Quand il monte → les acheteurs dominent. Quand il baisse → les vendeurs prennent le dessus.
🟢 Divergence haussière
Le prix baisse mais le CVD monte → des acheteurs accumulent discrètement malgré la baisse des prix.
Signal : retournement haussier probable. Les vendeurs s'épuisent, les acheteurs prennent le relais.
🔴 Divergence baissière
Le prix monte mais le CVD baisse → la hausse se fait sans conviction acheteuse.
Signal : distribution probable. Des vendeurs profitent de la hausse pour sortir.
💡 Utilisation pratique : Ne jamais utiliser le CVD seul. Combine-le avec le RSI (surachat/survente) et le volume. Une divergence CVD + RSI extrême = signal fort.

📌 Source des données : Bybit perpétuels linéaires (USDT). Intervalle recommandé : 1H pour le day trading, 4H pour le swing.

Support/résistance lointains. Objectifs long terme ou crashs d'urgence (1J+).

🔗 Heatmap Corrélations

Une heatmap corrélation montre comment les cryptos se déplacent ensemble (0 à 1).

🟢 Vert (0.0 - 0.3)
Pas correlées = bouger indépendamment = SAFE pour diversifier
🟡 Jaune (0.3 - 0.6)
Partiellement corrélées = bouger ensemble parfois
🔴 Rouge (0.6 - 1.0)
Fortement corrélées = bouger presque ensemble = RISQUE si l'une crash

Exemple :

  • BTC ↔ ETH = 0.78 (🔴) → Si BTC baisse 10%, ETH baisse ~8%
  • BTC ↔ DOGE = 0.16 (🟢) → DOGE peut baisser 5% quand BTC baisse 10%

💡 Conseil : Pour diversifier, choose des cryptos avec corrélations basses (vertes)

📊 À Quoi Sert le Risk Monitor ?

Le Risk Monitor analyse le risque de 9 cryptocurrencies majeures en combinant 4 indicateurs clés :

📊 Volatilité 24h
Mesure les fluctuations de prix sur les 24 dernières heures. Plus élevée = prix bouge beaucoup = risqué
💧 Liquidités
Capacité à acheter/vendre sans impacter le prix. Basse liquidité = difficile à sortir = risqué
🐋 Concentration
% du volume détenu par les gros holders. Concentration élevée = whale peut dump = risqué
🔗 Corrélation Système
Comment l'asset se déplace avec les autres. Corrélation élevée = risque systémique si BTC crash

Les 9 Cryptos Analysées :
BTC, ETH, SOL, BNB, XRP, DOGE, ADA, AVAX, MATIC

Score Final (1-10) :

  • 🟢 1-3 : BAS RISQUE — Safe, peu volatilité
  • 🟡 4-5 : MODÉRÉ — Normal, à surveiller
  • 🟠 6-7 : ÉLEVÉ — Attention, risqué
  • 🔴 8-10 : CRITIQUE — Très risqué, avoid

💡 Conseil : Use le Risk Monitor pour identifier les assets risqués et ajuster ton portefeuille. Les clusters te montrent quels assets bougent ensemble pour mieux diversifier.
