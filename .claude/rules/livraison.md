# Règle — Format de Livraison

## Format standard

Tout livrable suit ce format :

```
✅ [{livrable}] terminé

→ Ce qui a été fait :
  - {action 1}
  - {action 2}

→ Fichiers modifiés :
  - `{chemin}` — {créé|modifié|supprimé}

→ Prochaine étape suggérée :
  {description de l'étape suivante logique}
```

## Principes

- Toujours vérifiable : l'utilisateur peut contrôler le résultat.
- Inclure les chemins complets des fichiers touchés.
- Proposer la prochaine étape — ne pas laisser l'utilisateur dans le vide.
- Si plusieurs livrables : un bloc par livrable.
